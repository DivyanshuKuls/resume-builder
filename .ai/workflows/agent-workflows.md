# Next Backlog Item Workflow

When asked to continue development:

1. Review:
   - docs/backlog.md
   - docs/architecture.md
   - TECH_DEBT.md
   - current codebase

2. Identify:
   - highest-priority incomplete backlog item
   - dependencies
   - architectural risks
   - regression risks

3. Recommend the next item with rationale.

4. Generate:
   - implementation plan
   - architecture considerations
   - production-quality implementation prompt

5. WAIT for user approval before implementation.

Do NOT automatically begin large feature implementation without confirmation.
